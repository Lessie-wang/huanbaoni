> 这是并行开发的"宪法"。`lib/` 共享层按此实现并冻结；`pages/*` 各 agent 只准**调用**这些接口，不准改契约。

## 一、BLE 契约（固件 ↔ H5，双方必须字符串完全一致）

| 项 | 值 |
|---|---|
| Service UUID | `19b10000-e8f2-537e-4f6c-d104768a1214` |
| 心率上行 HR (Notify) | `19b10003-e8f2-537e-4f6c-d104768a1214` |
| HRV 上行 RMSSD (Notify) | `19b10005-e8f2-537e-4f6c-d104768a1214` |
| GSR 上行 (Notify, P1) | `19b10006-e8f2-537e-4f6c-d104768a1214` |
| 指令下行 CMD (Write) | `19b10008-e8f2-537e-4f6c-d104768a1214` |
| 广播名 | `HuanbaoNi` |

- 上行数据格式：HR = int（BPM）；HRV = float（ms, RMSSD）；GSR = int（0–4095 原始值）。
- 下行指令：字符串 `"VIBRATE"` → 马达震 1–2s。（预留 `"VIBRATE:LONG"` 等扩展）
- Web Bluetooth 限制：页面须 HTTPS 或 localhost；连接须由用户点击手势触发；iOS Safari 不支持。

## 二、统一"戒指接口"（mock.js 与 ble.js 必须实现同一套，可无缝互换）

> pages 只认这个接口，不关心背后是真硬件还是 mock。切换只改一行 `const ring = USE_MOCK ? new MockRing() : new BleRing()`。

```js
interface Ring {
  connect(): Promise<void>            // 连接（mock 立即 resolve）
  disconnect(): void
  vibrate(mode?: 'short'|'long'): Promise<void>   // 下发震动
  onData(cb: (d: RingData) => void): void         // 实时数据回调
  onStatus(cb: (s: RingStatus) => void): void     // 状态回调
  // 仅 mock 提供，用于演示/开发：
  simulateStress?(): void             // 手动触发一次压力冲高
}

type RingData   = { hr: number, hrv: number, gsr?: number, ts: number }
type RingStatus = 'idle'|'connecting'|'connected'|'baseline'|'monitoring'|'disconnected'
```

## 三、数据 Schema（localStorage，key 前缀统一 `hbn.`）

> 所有页面读写数据**只经 store.js**，不许各自直接 `localStorage.setItem`。字段冻结如下。

```js
hbn.events    // 情绪/压力事件时间线
[{ id:string, ts:number, type:'stress'|'manual',
   level:'low'|'mid'|'high', hr:number, hrv:number, gsr?:number,
   mood?:string, note?:string, source:'ring'|'user' }]

hbn.portraits // 心灵画像
[{ id:string, date:'YYYY-MM-DD', imgUrl:string /*dataURL*/,
   palette:string[], interpretation:string, moodSummary:string }]

hbn.growth    // 成长系统（沿用知愈 game-system 字段）
{ level:number, exp:number, totalExp:number, badges:string[],
  streakDays:number, lastActive:string, ringHugCount:number }

hbn.profile   // 用户画像 + 表达能力档案（搬知愈）
{ onboarding:object, expressionProfile:{strengths:[],blocks:[],practicing:[],milestones:[]} }

hbn.settings  // 运行配置
{ apiBaseUrl:string, apiKey:string, useMock:boolean }
```

store.js 必须导出：`getEvents/addEvent/getPortraits/addPortrait/getGrowth/setGrowth/getProfile/setProfile/getSettings/setSettings`。

## 四、AI 调用契约（ai.js，页面只调这三个函数）

```js
AI.config({ baseUrl, apiKey })                 // 读 hbn.settings 初始化
AI.chat(messages, { model }): Promise<string>  // 文本：小知/复盘/解读/测试分析
AI.image(prompt, { size='1024x1024' }): Promise<string /*dataURL*/>  // 心灵画像
```
- OpenAI 兼容：`fetch(baseUrl + '/chat/completions')` / `/images/generations`。
- 默认模型：chat → `gpt-5.6-sol`（兜底 DeepSeek）；image → `gpt-image-2`。
- 小知 system prompt 直接搬 `zhiyu-miniapp-1.2.0/utils/ai.js`。
- 不传敏感数据（OnePage 安全条款）。

## 六、mock 数据行为（mock.js，让软件不等硬件）

- 连接后 2s 内 `onStatus('connected')` → 5s 采基线(`'baseline'`) → 之后 `'monitoring'`。
- 每 1s 推一次 `RingData`：静息 HR 68–78、HRV 40–60ms、GSR 平稳。
- `simulateStress()`：15s 内 HR 升到 95+、HRV 掉到 20 以下、GSR 抬升 → 触发一次"高压力"，页面据此发 `vibrate()` 并写 `hbn.events`。
- `vibrate()`：mock 里 console.log + 页面弹个"戒指震动"提示即可。
