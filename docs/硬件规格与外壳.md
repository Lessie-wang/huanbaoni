## 三、外壳两段式设计（更新：双独立 Type-C 孔，去掉 3D 指套）

```
① 底座盒 (藏电路)                    ② 盒顶模块 (贴手指/敲击)
┌──────────────────────────┐        ┌─────────────────┐
│  面包板平铺盒底 56×165        │        │ MAX30102 感光窗朝上 │← 手指按压测 HR/HRV
│  ESP32 平放, 双Type-C朝端墙   │◄─线──│ MPU6050 敲击/晃动    │← 敲=双击唤醒, 晃=运动
│  麦克风板 + GSR底板 固定盒内   │        └─────────────────┘
│  端墙: ⊙⊙ 两个独立 Type-C 孔  │
│  上盖可开合 (唇卡合)          │        ③ 佩戴 (不做 3D 指套)
│  侧面: GSR电极线 + 马达线 出口  │◄─线──  GSR 自带指套电极(3.5mm)戴手指
└──────────────────────────┘              振动马达贴手指 / 绑在 GSR 指带上
     盒外只有两根线: GSR电极线 + 马达线, 其余全藏盒内
```

### 设计要点
- **底座盒内腔**：≥ 60 × 170 × 32mm（面包板 56×165×8.5 平铺 + ESP32 + 走线余量）。
- **双 Type-C 开口**：**两个独立矩形孔**（非大槽），孔略放大到 11 × 6mm 吸收误差；⚠️两孔**中心间距**是最需核对的参数（`.scad` 顶部变量 `usb_center_spacing`，默认 13mm 为估值，试打前务必量准或直接试插微调）。ESP32 在盒内位置可滑动对准两孔。
- **盒顶传感器位（工/L 双托盘）**：
  - **MAX30102（工字托盘）**：排针在**左右两条边（4+4=8）**、连接器朝下 → 盖顶开定位浅槽嵌板身（传感器面朝上供手指按），**中间细支撑柱托起板**（`max_bridge_w=4.5`，已从 8.5 减半以让出板底元件/排针空间），**两侧各一条到板边的贯通槽**（`max_slot_l=20` 加长少留边距）让排针+杜邦线朝下穿入（形如"工"字）。
  - **MPU6050（单边 L 横槽）**：排针只在**一条边（单排 8 针）** → 定位浅槽 + **一条大横槽**（`mpu_slot_l=22` 加长到满板长、上下不留边距，否则排针放不下卡住）给单排针穿下（形如"L"）。
  - `.scad` 参数：MAX `max_open_w/max_bridge_w/max_slot_l`；MPU `mpu_slot_w/mpu_slot_l/mpu_edge_off`；两者远端聚拢（`max_pos_from_end=160`、`mpu_pos_from_end=133`）让出中部给 hero。
- **GSR + 马达**：底板装盒内，**侧墙开两个圆孔**（`wire_hole_z=22` 抬高避开面包板；`wire_hole_gap=14`）分别走 **GSR 电极线** 和 **马达线** 出盒。
- **佩戴（简化）**：不打 3D 指套，直接用 **GSR 自带的指套电极**（3.5mm 插头 + 魔术贴指带）戴手指测皮肤电；**振动马达**贴手指或绑在 GSR 指带上感受私密震动。
- **上盖**：唇卡合可拆，方便调线；ESP32 通过端墙两 Type-C 孔即可插线烧录。

### 演示交互
| 动作 | 触发 | 现象 |
|---|---|---|
| 手指按盒顶 | MAX30102 测 HR/HRV | H5 仪表盘数值跳动 |
| 晃动盒子 | MPU 运动量 ↑ | H5 运动 (°/s) 上升；算法运动门控 |
| 敲 MPU 模块两下 | 双击手势 DBLTAP | 小知页开始/停止录音 |
| 压力升高 | 算法触发 | 指套马达私密震动 + 时间线记录 |

## 三·五、环抱手臂（品牌记忆点 · 分体打印）

> 让盒子真的被两只手臂**环抱**住，双手在盒顶**十指相扣**兼当盖子卡扣——呼应「环抱你」内核。

```
        ╭─双手在顶部相扣(压住盖子)─╮
   左臂 │   (( 环抱你 ))          │ 右臂
   从左 ╰──翻过盖沿────翻过盖沿──╯ 从右
   长边升起                        长边升起
   ↑贴墙圆形凹座(圆对圆)          ↑贴墙圆形凹座
```

- **成型方式（已定）**：手臂**单独打印**成第二色配件，再**胶合**到盒体两长边（长边中点 `embrace_y=out_l/2`）。分体好处：无悬空支撑、可换色、造型能更夸张优雅。
- **闭合机制**：两臂锚在**底座盒**上，双手翻过盖沿在顶部相扣、压住盖子 → 盖被"夹"在双手(上)与盒体(下)之间；盖顶对应位置有**双手落座浅窝**定位。掀手即可开盖。
- **安装（圆形凹座，圆对圆自对位）**：盒体两长边各有一处**圆形凹座**（`socket_d=13`、中心高 `foot_cz=13`、深 `foot_recess=1.2mm`），与**圆形手臂根部**形状匹配；手臂根部为**圆柱榫**（直径 `socket_d-0.6` 嵌入凹座 + 凸出墙外 blend 进手臂）对位后胶合（AB 胶/强力胶）。圆对圆比矩形更贴合手臂、自动对中。
- **建模**：`arm(s)` 模块，`s=+1` 右臂 / `s=-1` 左臂；`limb()` 用相邻球体 `hull()` 生成光滑锥形手臂，`hand()` 为连指手套式圆润手掌（无脆弱手指、好打印）+ 拇指；左右手 `hand_yoff=3.2mm` 错位形成**交错相扣**感。
- **含蓄有机曲面**：盒体顶沿加 `top_chamf=1.8mm` 内收倒角去硬边；配合四角圆角，整体柔和。**立体油画/impasto 质感建议在切片器用 Fuzzy Skin（模糊表皮）**给盒体外墙轻微加纹理（力度调小=含蓄），零建模成本、可控、不脆弱；盖顶刻字面**不要**开 Fuzzy Skin。

### 配合已核对（section 剖切验证 ✅）
- **脚 ↔ 浅槽**：脚榫 1mm 嵌入墙上浅槽，脚 `14×16` vs 槽 `14.6×16.6` → 每边约 0.3mm 定位间隙；左右对称（曾修一处左脚朝向 bug）。
- **手 ↔ 盖**：双手掌落在盖顶（z≈37）之上轻搭，配合盖顶落座浅窝定位（不再穿透盖板）。
- **真正闭合**：靠盖唇 `rrect(61.6)` 插入盒腔 `rrect(62)` 的单边 0.2mm 摩擦配合；双手为"环抱/夹持"叙事 + 轻压。
- 复核命令：`openscad -o section_check.png --camera=33,90,25,90,0,0,150 --projection=ortho -D 'show="section"' enclosure.scad`

### ⚠️ 装配顺序（重要）
> **必须先盖盖子、再粘手臂**。因双手悬在盖子中部上方，若先把手臂粘死在盒壁，盖子将无法竖直落入。正确流程：
> 1. 电路装入底盒 → 盖上盖子（唇摩擦到位）
> 2. 左/右手臂脚榫对入盒壁浅槽 → 胶合（AB 胶/强力胶），双手自然落在已就位的盖顶上
> 3. 需开盖时：PLA 手臂较细（腕 ⌀~6.4mm、悬臂 ~40mm）有弹性，轻抬双手即可掀盖；或视为半永久闭合。
