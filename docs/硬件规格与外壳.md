## 三、「环抱你·小白」立体角色外壳

> 外观不是盒子贴角色，而是一个无脸、无耳的抽象拥抱精灵。矩形电子仓只存在于梨形肚子的内部，任何外部视角都保持连续椭圆曲面。

### 空间与轮廓

- **内部净空**：`62 × 32 × 90mm`，半长面包板 `56 × 83 × 8.5mm` 竖装；ESP32、GSR、马达驱动和走线仍使用原规划深度。
- **主体外形**：约 `110 × 82 × 153mm`（不含向前伸出的抱臂）；由一条稠密的梨形曲线旋转成型，再做前后椭圆压缩，整个肚子是一张连续曲面。
- **整体握持深度**：含抱臂约 `117mm`；双臂前移后，肚子与前臂之间留 `hand_clearance=22mm` 净空。
- **识别方式**：无五官、无耳朵、无戒指或 Ring 字样；只用小头、梨形身体和“抱住人的手”的动作表达「环抱你」。
- **壳体结构**：身体沿左右侧轮廓分为前/后两半，接缝位于 `y=0`；后壳四枚 `⌀5.8mm` 球头扣入前壳带释压槽的卡座，保留约 0.35mm 配合量，可反复开壳调试。

### 握持交互

1. 用户从正面把手掌插入小白肚子与双臂之间。
2. 掌心自然压住正面的 MAX30102 H 型托盘，手指可以环握梨形肚子。
3. 小白的粗短 C 形手臂包在手掌两侧，掌球和大拇指位于内上侧，不压传感器。
4. `hand_clearance` 是单一可调参数；试握后只需改这个值即可前后移动整段抱臂。

### 功能接口布局（尺寸不变）

- **正面**：仅 MAX30102 H 型托盘，板槽 `15.5 × 20mm`、总开口宽 `17mm`、中桥 `4.5mm`、双侧贯穿槽长 `20mm`。
- **背面上方**：MPU6050 L 型托盘，板位 `16 × 21mm`、排针槽 `5 × 22mm`，方便直接敲击。
- **背面中部**：GSR 和马达两个 `⌀9mm` 圆孔，中心距 `14mm`。
- **真正底部（两脚之间）**：双 Type-C 独立孔，每个 `11 × 6mm`，横向中心距仍为待实测的 `13mm`。ESP32 在下腹中央竖装：PCB 宽 `27.9mm` 由左右导轨夹持，`57.2mm` 长轴沿身体高度，Type-C 短边垂直朝下。拿起小白即可插线，站立时两脚把接口架空；这避免了背向安装所需的 `63.3mm` 前后空间，也不占面包板后层。

### 工程校验

- `wall_check` 会将主电子仓和 ESP32 下腹板槽向外扩 2.4mm 后与梨形内壳求差（忽略底部 Type-C 开口所在的 `z<5mm`）；当前结果为空，表示所需净空完整装得下。
- 手臂通过隐藏的 `⌀7.4mm` 肩榫插入前壳，孔侧留 0.35mm 配合量，实际握持受力不只依赖胶面；手臂本体采用连续曲线扫掠网格，圆肩—圆肘—前臂之间没有分段锥面。
- 前壳、后壳、左右手臂均已通过 OpenSCAD CGAL 封闭实体检查。
- ⚠️ 试打前仍必须实测 `usb_center_spacing`，这是目前唯一沿用估值的关键接口参数。

### 文件与导出

- 参数化源文件：`hardware/enclosure.scad`
- 单件：`hardware/body_front.stl`、`hardware/body_back.stl`、`hardware/arms.stl`
- 一次排版：`hardware/print_all.stl`（前后壳接缝面朝下，双臂侧躺；适配 256 × 256mm 打印板）
- 预览：`hardware/assembled.png`、`hardware/assembled_front.png`、`hardware/assembled_back.png`、`hardware/assembled_side.png`
- `show`：`assembled` / `body_front` / `body_back` / `arm` / `arm_l` / `arms` / `grip_check` / `cavity_check` / `wall_check` / `print`

```bash
openscad -o hardware/body_front.stl -D 'show="body_front"' hardware/enclosure.scad
openscad -o hardware/body_back.stl  -D 'show="body_back"'  hardware/enclosure.scad
openscad -o hardware/arms.stl       -D 'show="arms"'       hardware/enclosure.scad
openscad -o hardware/print_all.stl  -D 'show="print"'      hardware/enclosure.scad
```

建议全体使用暖白 PLA；手臂与身体同色，靠真实体块和阴影表达拥抱，不再使用肤色贴件或表面角色图案。

## 四、打印时间优化

- 主体由“实心体块再挖矩形槽”改为约 `2.8–4.0mm` 的连续有机薄壳，外观、内部净空和所有接口坐标不变。
- 面包板和 ESP32 不再依赖大块实心托盘，改用两侧导轨、底托/顶挡和与壳体相连的短加强筋。
- 四枚球头卡扣各用一条窄径向筋连回后壳，位于 `62mm` 电子仓宽度之外，不会挤占元器件空间。
- 手臂仍为同一条连续扫掠曲面，只将网格采样从 `40×40` 降为 `28×28`；圆肩、圆肘和掌球的实际尺寸不变。
- STL 体积校验：前后壳合计由约 `528.7cm³` 降为 `187.6cm³`，减少约 **64.5%**。这是用料/打印时间的几何代理值；最终分钟数仍取决于层高、壁数、填充和支撑策略。

推荐切片起点：`0.24mm` 层高、3 道壁、15% 局部填充；前后壳用平整接缝面朝下，手臂侧躺并仅对悬空局部生成支撑。
