# 分工清单（实时任务看板）— 环抱你

> 并行开发的"作战地图"。每个 agent 只做自己那行，只碰"文件所有权"里属于自己的文件。
> 状态标记：⬜ 未开始 / 🟨 进行中 / ✅ 完成 / 🟥 卡住(交给你)
> 更新方式：你（总集成）每完成一块就改状态 + git commit。

---

## 0. 铁律（所有 agent 通用，写进每个 agent 的 prompt 开头）
1. 先读 `docs/接口契约.md`，**严格按契约**，不许改 `lib/` 里的接口签名与数据 schema。
2. **只准编辑分配给你的文件**（见下表），不许碰别人的文件。
3. 数据只经 `store.js`，样式只用 `tokens.css` 变量，AI 只调 `ai.js`，戒指只调统一 Ring 接口。
4. 纯 HTML+CSS+vanilla JS，无框架、无构建步骤，能在 `localhost` 直接打开跑。
5. 交付前自检：能打开、控制台无报错、用了 mock 能看到数据/交互。
6. commit 信息格式：`[模块名] 做了什么`。

## 2. 阶段二：软件模块（阶段一冻结后，A–F 并行）

| Agent | 模块 | 文件所有权 | 依赖 | 输出/验收标准 |
|---|---|---|---|---|
| **A** | 环抱(实时主页) | `pages/realtime.js` (+`realtime.css`) | Ring接口, store, tokens | 连接按钮→仪表盘出实时HR/HRV→三色压力环；压力"高"自动 `vibrate()`+写 `hbn.events`；有"测试震动"按钮。用 mock 全流程可演示 |
| **B** | 今日心灵画像 ⭐ | `pages/portrait.js` (+css) | ai(image), store | 读当日 `hbn.events` 汇总情绪→拼 prompt→`AI.image()` 生成画→显示+解读→存 `hbn.portraits`。生成慢时可用预置样张兜底 |
| **C** | 心迹(成长轨迹) | `pages/growth.js` (+css) | store, 搬game-system | 画像画廊(色调演变) + 情绪/压力趋势图 + 等级/徽章/连续天数 + "被环抱N次" |
| **D** | 小知(AI管家) | `pages/chat.js` (+css) | ai(chat), store | 对话界面；压力事件后主动发起复盘；system prompt 搬知愈；能读 `hbn.events` 做情境化复盘 |
