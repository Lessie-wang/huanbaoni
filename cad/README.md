# FeelingMosaic「环抱你」3D 打印原型 V1

## 设计结论

- 戒指定位为外观展示原型，不强行容纳 ESP32、MAX30102 开发模块和驱动板。
- 功能演示采用分布式原型：MAX30102 作为外置指夹采集，戒指或手部插件负责震动，ESP32 与驱动板放入底座。
- 戒指是开放式 C 环；两端为抽象双手，共同托住可拆卸六瓣情绪核心。
- 戒圈外有一条绕截面翻转一周的脊线，形成莫比乌斯视觉意象，同时不侵占主要佩戴空间。
- `FeelingMosaic` 字样在 Blender 精修阶段沿戒圈外侧雕刻；底座正面使用更大的品牌字样，保证 FDM 可读性。

## 现场设备约束

Buildathon OnePage 第六章列出的现场打印机型号为 Bambu Lab A1、P2S、X2D、H2D，提供 PLA：红、橙、黄、绿、蓝、黑、灰、白。文档没有列出透明耗材，并提醒硬件资源数量有限、对稳定性有要求时应自备材料。

因此：

- 默认使用白色 PLA 打印主体，灰色或黑色打印结构件。
- 莫兰迪粉棕、香槟金细节通过自带耗材、丙烯笔或喷漆实现。
- “透明底座”不是全透明 PLA，而是开放框架加 0.5-1 mm PET/亚克力透明片。
- 比赛前优先打印戒指和底座；现场打印只作为迭代或备用。

## 戒指参数

| 版本 | 内径 | 用途 |
|---|---:|---|
| S | 18.5 mm | 食指偏细 |
| M | 19.5 mm | 默认版本，优先打印 |
| L | 20.5 mm | 食指偏粗或需要宽松佩戴 |

- 戒圈总宽约 6 mm，最小主体厚度约 3.4 mm。
- 开口角约 60°；PLA 不应反复掰折，建议通过三种尺寸选配，而不是依赖弹性调节。
- 六瓣核心单独打印，可使用两枚 3×2 mm 磁铁或少量可移胶固定。
- 抽象手指直径约 1.1 mm，已按 0.4 mm 喷嘴的可打印下限加粗。
- 可选震动插件预留常见 10 mm 纽扣马达空间；驱动板仍放在底座。

## 底座架构

### 共用电子托盘

- 外形：140×95×12 mm。
- 内部用于放置 ESP32-S3、400 孔面包板、马达驱动板及杜邦线。
- 两条内部导轨用于扎带、双面胶或魔术贴固定。

### 封闭展示版

- 使用 `opaque_emotion_island_lid` 覆盖电子托盘。
- 顶部六瓣浮雕和戒指展示架构成“情绪岛屿”。
- 后侧预留 USB 走线区域；最终精修时再按实物线头开孔。

### 开放透明版

- 使用 `open_clear_panel_frame` 安装在电子托盘上。
- 四周框架之间安装 PET、亚克力或透明包装片，展示内部原型结构。
- 不使用现场未列明的透明 PLA，避免成品浑浊且打印失败。

## 手上震动演示

优先方案：

1. 购买 10 mm 左右、已带引线的纽扣震动马达。
2. 将马达放入 `optional_10mm_coin_motor_insert`。
3. 插件用医用双面胶、透明胶贴在食指侧面或戒指下方。
4. 细线沿手背进入袖口，再连接底座中的驱动板。

无小马达时：将现有带驱动板的震动模块固定在手腕内侧，用腕带遮住，仍能保证震动真实发生在手上。

## 推荐切片参数

- 材料：PLA。
- 喷嘴：按现场机器默认设置；模型按常见 0.4 mm 喷嘴设计。
- 层高：戒指 0.16-0.20 mm；底座 0.24-0.28 mm。
- 墙数：戒指 3-4；底座 2-3。
- 填充：戒指 25-35%；底座 10-15%。
- 支撑：戒指建议树状支撑，仅从热床生成；底座主体尽量不加支撑。
- 首次打印顺序：M 戒指 → 六瓣核心 → 震动插件 → 电子托盘 → 选一个底座上盖。

## Blender 精修清单

1. 对戒指主体执行 Voxel Remesh 或 Boolean Union，消除重叠壳体。
2. 沿戒圈外侧雕刻 `FeelingMosaic`，字高不小于 2.5 mm、笔画不小于 0.8 mm、深度 0.5-0.7 mm。
3. 在六瓣核心和双手托座增加 3.2×2.2 mm 磁铁孔。
4. 根据实物 USB 插头、开关和线材尺寸修改底座开孔。
5. 使用 Bambu Studio 的模型修复功能检查非流形边并预览逐层切片。
