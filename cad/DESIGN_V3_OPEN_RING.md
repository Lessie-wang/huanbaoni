# FeelingMosaic「环抱你」开口戒指 V3

## 当前推荐方案

V3 保留 V2 的高级几何与莫比乌斯语言，但完全移除中央宝石：

- 戒指是清晰的开放式 C 环。
- 八面切角截面沿戒圈扭转 180°。
- 两端抽象为相向伸出的几何双手。
- 中央最窄开口约 5 mm，没有宝石、横梁或隐藏连接件。
- 三根渐细指片与下方拇指共同框出负空间，表达“想要拥抱但不过度侵入”。

## 推荐外观

- 首选：枪灰或钛灰哑光主体。
- 备选：哑光银主体，切面边缘轻微抛光。
- 不建议粉色、圆润高光或彩色花朵装饰。
- `FeelingMosaic` 后续刻在戒圈较宽的外侧切面，或只刻在戒指内壁。

## 输出文件

路径：`cad/output/open_v3/`

- `feelingmosaic_open_embrace_ring_18.5mm.stl`
- `feelingmosaic_open_embrace_ring_19.5mm.stl`（默认）
- `feelingmosaic_open_embrace_ring_20.5mm.stl`

每个 STL 同时提供 OBJ。

## 尺寸与打印

- 默认内径：19.5 mm。
- 默认外形约：32.4×33.7×6.0 mm。
- PLA 层高：0.12-0.16 mm。
- 墙数：4；填充：30-40%。
- 建议以开口向上、整体倾斜 30-45° 的方式打印，并使用树状支撑。
- 当前文件由多个封闭实体组成；导入 Bambu Studio 后使用“修复模型/合并重叠体”，或在 Blender 中执行 Voxel Remesh 后再切片。
